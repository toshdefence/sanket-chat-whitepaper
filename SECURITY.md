# Reporting a security issue

If you believe you have found a vulnerability in SANKET, please report it privately to
security@toshdefence.com rather than opening a public issue. Include enough detail to reproduce it and, if
you can, the release you tested.

Please allow time for a fix to reach customer installations before any public disclosure. Reports are
acknowledged and handled in confidence.

This repository holds the public edition of the SANKET Technical Security & Architecture Whitepaper. It does
not contain product source code.
