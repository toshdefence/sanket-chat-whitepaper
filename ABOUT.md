# About SANKET and Tosh Defence

## About SANKET

SANKET (संकेत, "signal") is a sovereign secure communications platform built by Tosh Defence for defence forces,
government departments, intelligence and law-enforcement agencies, critical infrastructure operators and other
organisations whose communications must stay confidential even if the network, the hosting provider or the
communications provider cannot be trusted.

- **End-to-end encrypted messaging, file exchange, voice and video calls and priority broadcast**, built on Signal's
  official, audited libsignal library (PQXDH and the Double Ratchet with post-quantum protection) and AES-256.
- **Server-blind content:** the server relays ciphertext and never holds the keys to read messages, files, calls,
  reactions or encrypted broadcasts.
- **Sovereign and self-hosted:** one dedicated installation per organisation, on infrastructure it owns, including
  closed and air-gapped networks, with no third-party analytics and no foreign runtime dependency.
- **Organisational control:** administrator security keys, device approval and revocation, signed device lists,
  device mutual TLS, hash-chained audit logs and signed, verifiable releases.
- Native apps for Android, iOS, Windows, macOS and Linux.

SANKET is offered as Sanket.Chat, Sanket.Work (managed, whitelabel deployment for sensitive organisations) and
Sanket.Enterprise (air-gapped, on-premise deployment for defence and government). Details: [www.sanket.chat](https://www.sanket.chat).

The full security design is in the [SANKET Technical Security & Architecture Whitepaper](README.md).
